# Personal Portfolio Website - Harsh Patel

Personal portfolio website project built for the university Web Design coursework at the New Jersey Institute of Technology (NJIT).

## Project Overview
This repository contains a 5-page static personal portfolio showcasing civil engineering technology, building information modeling (BIM), embedded systems, and technical leadership projects.

- **Developer:** Harsh Patel
- **Institution:** New Jersey Institute of Technology (NJIT)
- **Course:** Midterm Project: Portfolio Web Design

## Planned Pages
- `index.html` - Home & Professional Introduction
- `about.html` - About Me, Academic Background, and Experience
- `projects.html` - Engineering Projects & CAD/BIM Showcases
- `skills.html` - Technical Skills & Competency Matrix
- `contact.html` - Contact Information & Inquiries
